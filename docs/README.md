# 対戦テトリス 設計書

## 再現の基準

基準は **PPT2 Ver.1.3.2 の調整を反映した通常 VS、双方標準設定** とする。2021-07-01 の更新では、REN 火力、ソフトドロップ速度、接地時の硬直が変更された。したがって、前作や PPT2 発売時点の数値を無条件に流用しない。[SEGA 公式更新情報](https://puyo.sega.jp/puyopuyotetris2/information.html)

実機照合時には機種・実際のバージョン・対戦設定を記録する。今回、PPT2 自体を実行して計測してはいない。全プラットフォームの最新版が完全に同じ挙動であるとも断定しない。『ぷよぷよテトリス2S』、対ぷよ、スキルバトル、スワップ、アイテム、3〜4人戦は初期対象外。

設計上の数値には次の区分を付ける。

| 区分           | 意味                                                                                   |
| -------------- | -------------------------------------------------------------------------------------- |
| **公式確認**   | 対象作品の公式資料に記載がある。記載範囲だけを確定事項とする                           |
| **実演資料**   | プレイヤー本人の図解・実演・検証を根拠とする。公式仕様ではなく、手元の実機照合は未実施 |
| **共通モデル** | 公開研究などの回転・乱数モデルを採用。PPT2 との完全一致の証明ではない                  |
| **暫定**       | 実装を進めるための本プロジェクトの決定。実機計測で置き換える                           |

## 初期リリースの範囲

- 1人練習、ローカルでの2盤面検証、招待ルームによるオンライン1対1。
- 左右移動、左右90度回転、ソフト／ハードドロップ、HOLD 1個、NEXT 5個、ゴースト。
- T-Spin／Mini、B2B、REN、全消し、攻撃予告、相殺、おじゃまのせり上がり。
- 2本先取を初期値とするラウンド戦、再戦、切断処理、入力リプレイ。
- キー割り当て、音量、色と模様によるミノ識別。演出・画像・音楽は独自に制作する。

レーティング、公開マッチング、観戦、CPU、モバイル操作は後続とする。ゲームルールは `ppt2-vs-draft-1` のように版を付け、対戦開始時に固定する。初版を「完全互換」とは扱わず、検証表を埋めながら近づける。

## 最初に固定する要点

| 項目        | 初版の方針                                                         |
| ----------- | ------------------------------------------------------------------ |
| 回転        | 標準 SRS の90度回転。I 専用のキック表を使う                        |
| 出現        | 7種1巡。公平性のため両者で同じミノ列を使用する方針                 |
| HOLD / NEXT | HOLD 1個、固定まで再使用不可、NEXT 5個                             |
| 基本火力    | Single 0 / Double 1 / Triple 2 / Tetris 4                          |
| T-Spin 火力 | Single 2 / Double 4 / Triple 6、Mini Single 0 / Mini Double 1      |
| B2B         | 対象のライン消去が継続したとき +1                                  |
| REN         | 0〜1: +0、2〜3: +1、4〜5: +2、6〜7: +3、8〜12: +4、13以上: +5      |
| 全消し      | 攻撃合計を10に置き換える初版仕様。B2B／RENの重複加算は実機検証対象 |
| 通信        | サーバーが判定を確定し、手元は先行表示して補正する                 |
| インフラ    | 国内1リージョン・常駐ゲームサーバーから開始                        |

火力表の根拠は、更新後の PPT2 を扱うプレイヤーの実演記事。細部の区分・計算例は[ゲームルール](game-rules.md)に記載する。[せるりあんによる解説・実演](https://note.com/blueceru55/n/n053fc510e19b)
