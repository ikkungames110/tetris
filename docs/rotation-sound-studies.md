# 回転音の10案

前回のA/B/Cは共通の単音モチーフと似た倍音構成が中心で、音色の幅が足りなかった。回転Aは587 Hzへ向けて約17%上昇する短い音程変化があり、ユーザーから「キュッキュッして心地よくない」と指摘された。

今回は音程の連続的な滑りを全案で使わず、発音方式・リズム・倍音・余韻から別々に設計する。「コロコロした軽さ」を軸に、シンセもアナログ・FM・チップ・和音の4方向に分ける。

| 番号 | 名前               | 方式・差別化                                                             | 秒   |
| ---- | ------------------ | ------------------------------------------------------------------------ | ---- |
| 01   | 木玉ころころ       | 非整数倍音の木質音を3打。後ろの2打を小さくして転がりを表す               | 0.19 |
| 02   | 水滴ポロン         | 大小2滴の澄んだサイン波。固定音程の間隔と発音タイミングで水滴感を作る    | 0.22 |
| 03   | 小さな泡           | 低音の3粒と振幅変調。音高のうねりを使わずプルルと弾ませる                | 0.18 |
| 04   | アナログ・プラック | ノコギリ波を2段ローパスで丸める減算合成。共振を付けず、電子音の芯を残す  | 0.16 |
| 05   | FMエレピ           | 固定キャリアと減衰するFM変調。電気ピアノ寄りの柔らかな金属感             | 0.23 |
| 06   | まるいチップ音     | 帯域制限した三角波の二音。短い離散音程でレトロなゲーム感                 | 0.15 |
| 07   | ナイロン・プルン   | Karplus–Strong弦モデル。滑らかなノイズ励振を循環・減衰させて撥弦感を作る | 0.25 |
| 08   | 小粒シェイカー     | 帯域制限ノイズの4粒。音程を抑えた粒感でBGMに馴染ませる                   | 0.14 |
| 09   | 陶器トロン         | 510 Hzと非整数の共鳴モード。木より澄んだ余韻と弱い接触音                 | 0.24 |
| 10   | クラウド・シンセ   | add9和音と微小デチューン。打撃を抑えた短いゲートで空気感を作る           | 0.26 |

音量だけで好みが決まらないよう、1回の発音エネルギーを220 msの基準窓で約−29 dBFSに揃え、ピークを最大−13 dBFSに制限する。各音は中央定位、44.1 kHz・ステレオ・192 kbps MP3。アタックと終端を滑らかにし、長い残響は付けない。素材はすべて独自の波形合成で、名前は表現したい質感を示すもの。実物の録音ではない。

各案の単発MP3に加え、ゆっくり4回（340 ms間隔）→速く6回（140 ms間隔）の2.8秒の連続回転デモを作る。連続版も同じ音量で重ね、余韻の重なりや耳への負担を比較できるようにする。数値検証はデコード・ピーク・エネルギーを対象とし、心地よさの最終判断はユーザーの試聴で行う。

公開試聴ページは `/rotation-preview/`。Vite開発サーバーでは `/rotation-preview/index.html`。今回の10案は選定用で、ゲームに採用中のAは変更しない。

```bash
python3 scripts/generate-rotation-se.py --ffmpeg /path/to/ffmpeg
```

出力先は `public/rotation-preview/`。単発10個、連続版10個、設計・計測値を含む `manifest.json` を生成する。既存のSEとPerfect clear音源は触らない。
