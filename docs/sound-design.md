# 操作SEの試作

6用途 × 3パターンの18個と、Perfect clear用の1個を、録音素材を使わず波形合成で制作。通常回転は03・08・10から選択（初期値03）。その他の用途はAをゲームに採用。試聴ページは `/se-preview/`、MP3は `public/se-preview/` に配置する。

## 差別化の設計

聞き分けは音量だけに頼らず、音域・音の数・音程の動き・長さで作る。操作音は短く中央に置き、消去音は少し広げる。全用途で同じ五音音階を中心に使い、音が重なったときの濁りを抑える。

| 用途                 | 音の形                                 | 長さの目安   | 狙い                                                 |
| -------------------- | -------------------------------------- | ------------ | ---------------------------------------------------- |
| ミノ設置             | 低めの単音＋短い打撃成分、わずかに下降 | 0.12〜0.16秒 | 着地の手応え。連続設置でも邪魔にならない             |
| 回転                 | 中高域の単音、わずかに上昇             | 0.09〜0.13秒 | 入力への軽い応答。設置より高く短い                   |
| 回転（T-spin）       | 上昇する二段音＋小さな収束音           | 0.20〜0.25秒 | はめ込んだ手応え。通常回転と区別し、消去ほど祝わない |
| ライン消去           | 上昇する二音                           | 0.32〜0.40秒 | 簡潔な達成感。1〜3ラインで使う基礎音                 |
| ライン消去（T-spin） | 短い音程のひねり→三音の和音            | 0.52〜0.64秒 | テクニカルな成功を表現。4LINEの階段とは異なる形      |
| ライン消去（4LINE）  | 四段の上昇→開いた和音                  | 0.68〜0.82秒 | 4段をリズムで伝え、余韻で大きな達成感を出す          |

## 3つの音色

- **A / Wood（木琴）**：丸い基音と弱い木質の倍音。低刺激で、長時間のプレイ向きの第一候補。
- **B / Glass（ベル）**：軽いFMと早く減衰する倍音。澄んだ輪郭と短いきらめき。
- **C / Soft synth（電子音）**：サイン波を中心に弱い奇数倍音。少し弾む音程でゲームらしい応答。

3案は同じ操作のモチーフを保ち、音色を比較できるようにする。MP3は44.1 kHz・ステレオ・192 kbps。アタックと終端を滑らかにし、操作音には長い残響を付けない。音源ピークは操作音で約−15〜−17 dBFS、通常消去で−12 dBFS、特殊消去でも−9〜−10 dBFSとし、重なりに余裕を持たせる。低音の手応えだけに頼らず、小型スピーカーでも聞き取れる倍音を加える。知覚音量の最終判断はBGMと実機での試聴で行う。

## ゲームへの適用

- 今回追加された `src/se/4LINES.mp3` を4ライン同時消去で鳴らし、T-spinと同じ位置・期間で `4LINES` を表示する。
- 通常回転は03・08・10から選択し、その他の用途はAを採用。ゲームの最初の音声解放時に選択可能な回転音3つ・Aの設置／T-spin回転／消去音・Perfect clear専用SE・各ボイスを先読みする。T-spin／Miniと4LINEの既存音声はAの消去SEに重ねる。ラインを消さないMini設置では設置SEとMini音声を鳴らす。
- 成功した回転のみ音を鳴らす。T-spin回転音はTミノが回転後の位置でスピン条件を満たした操作へのフィードバックとし、設置時に確定するT-spin消去音とは区別する。失敗した回転や、Tミノを空中で回しただけの操作では特殊音を鳴らさない。
- 消去を伴う設置では消去音を優先し、設置音との重なりを避ける。T-spinと4LINEの消去音を通常消去音に重ねない。

## 再生成

Python 3（標準ライブラリーのみ）と、`libmp3lame` を使えるFFmpegを用意して実行する。

```bash
python3 scripts/generate-se.py
# FFmpegがPATHにない場合
python3 scripts/generate-se.py --ffmpeg /path/to/ffmpeg
```

スクリプトは18個の比較用MP3とPerfect clear用MP3、長さ・ピーク・RMSを記録した `manifest.json` を生成する。乱数シードを固定し、同じFFmpeg環境では再現可能。ユーザー提供の `src/se` 内の音源は編集しない。

## Perfect clear専用SE

約1.8秒。Aの木琴を基礎に、8音の上昇フレーズ、低音、左右に広がるC major add6の和音、薄いベルの余韻を重ねる。4LINEの約0.7秒より長く、音量を上げるだけでなく音数・広がり・余韻で最も華やかにする。音源ピークは−9 dBFS。

Perfect clearは1〜4ラインすべてで最優先。`perfect_clear_a.mp3` とユーザー提供の `src/se/Perfect_clear.mp3` を同じWeb Audio時刻に予約し、それ以外の消去音・消去ボイスを重ねない。ミックス係数はSE 0.85、ボイス0.9で、どちらも既存のSE音量設定に従う。片方のダウンロードに失敗しても、取得できた音源は鳴らす。

Perfect clearだけを再生成する場合：

```bash
python3 scripts/generate-se.py --perfect-only --ffmpeg /path/to/ffmpeg
```

## 回転音・対戦・リプレイ

回転直後に共通エンジンのT-spin判定を使い、通常回転とT-spin回転（Full／Mini）を分ける。失敗・左右同時回転・HOLDで処理を終えた場合は回転音を出さない。回転後に移動してスピン条件を失った場合、設置時の消去音はその最終判定に従う。

回転通知はゲーム状態の検証値から除外した `rotationSounds`（1 tickあたり最大2件）で渡す。オンラインでは回転のあるtickも両端末に配信し、同じtickの再受信では再生しない。回転は確定した状態で鳴らし、先行表示の再計算では鳴らさない。Perfect clearの音声メタデータも検証値から除外し、既存のリプレイ・40LINE記録の互換性を保つ。

## 回転音の開発用切り替え

設定「BGM・音量」の「回転音（開発用）」で03（小さな泡）・08（小粒シェイカー）・10（クラウド・シンセ）を選択できる。初期値と旧設定・不正値のフォールバックは03。`tetcla-audio-v1` の `rotationSound` に保存し、ローカル・リプレイ・オンラインの通常回転に即時適用する。T-spin回転は既存の専用Aを使用する。

試聴ボタンはゲームと同じ再生経路・SE音量を使用する。03・10のミックス係数0.85に対し、08は0.55（約−3.8 dB）に下げる。比較用MP3自体は保存し、ゲーム内の再生ゲインで調整する。
