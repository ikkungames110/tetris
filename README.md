# STACK — 対戦テトリス

ぷよぷよテトリス2の通常テトリス対戦に近いルールを目指す、ブラウザー向けゲームです。現在の初版は **1人練習・同じ端末での2人対戦・DualShock 4入力** に対応しています。

## 起動

Node.js 24 LTS推奨（最低22.12）。

```bash
npm ci
npm run dev
```

[http://localhost:5173](http://localhost:5173) を開いて「プレイする」を押します。ゲームパッドは **localhost または HTTPS** で使ってください。別端末からHTTPのLANアドレスで開くと、ブラウザーの制限によりゲームパッドを取得できない場合があります。

WSLで作業する場合は、Node.jsとnpmもWSL側にインストールしてください。Windows側のnpmが呼ばれると、`CMD.EXE`のUNCパスエラーや`vite`が見つからないエラーで起動できません。WSLのターミナルで次を確認できます。

```bash
command -v node npm  # 両方ともLinux側のパスであること（/mnt/c/... はWindows側）
node -p 'process.platform'  # linux
```

Node.jsをインストールした直後も以前のnpmが呼ばれる場合は、`hash -r`を実行するか、WSLのターミナルを開き直してください。Windows側のnpmを使っていた場合は、WSL側で`npm ci`を実行して依存関係を入れ直してから`npm run dev`を実行します。`Port 5173 is already in use`なら、すでに起動しているゲームを上記URLで開くか、そのサーバーを停止してから再実行してください。

```bash
npm run build     # 型チェック＋配信用dist生成
npm run preview   # ビルドしたゲームを確認
```

## 遊び方

- 「ひとりで練習」ではおじゃまを受けずに練習できます。
- 「ふたりで対戦」は同じ画面での2本先取。両者のミノ出現列は同じです。
- 「操作設定」で各プレイヤーにキーボードまたはゲームパッドを割り当てます。
- 1台のキーボード、キーボード＋パッド、2台のパッドで対戦できます。1台のパッドを両者に割り当てることはできません。
- Esc / OPTIONS で一時停止・再開。画面が非アクティブになったとき、使っているパッドが切断されたときも一時停止します。
- 「終了」でモード選択へ戻れます。「はじめから」は現在のゲームをリセットします。
- 「リプレイ保存」で入力をJSONに保存し、「リプレイ再生」で再生できます。最後に状態ハッシュの一致を確認します。

### キーボード

| 操作            | キーボード1 | キーボード2 |
| --------------- | ----------- | ----------- |
| 左 / 右移動     | ← / →       | A / D       |
| ソフトドロップ  | ↓           | S           |
| ハードドロップ  | Space / ↑   | W           |
| 左 / 右回転     | Z / X       | Q / E       |
| HOLD            | C / 右Shift | F           |
| 一時停止 / 再開 | Esc         | Esc         |

### DualShock 4

OSにUSBまたはBluetoothで接続し、ページを開いてパッドのボタンを一度押してください。最初に認識したパッドは、ゲーム開始前であれば1Pに自動で割り当てます。「操作設定」から変更できます。

| 操作                   | 標準の割り当て |
| ---------------------- | -------------- |
| 左 / 右移動            | 十字キー ← / → |
| ソフトドロップ         | 十字キー ↓     |
| ハードドロップ         | 十字キー ↑ / △ |
| 左回転                 | × / □          |
| 右回転                 | ○              |
| HOLD                   | L1 / R1        |
| 開始 / 一時停止 / 再開 | OPTIONS        |

ブラウザーの Gamepad API が `mapping: "standard"` として公開した配置を使います。標準マッピングされない接続では、「操作設定」で各ボタン・方向を登録してください。登録はブラウザーに保存します。左スティックの移動は設定から有効にできます。ドリフト対策のデッドゾーンがあり、スティック上ではハードドロップしません。[W3C Gamepad API・標準配置](https://www.w3.org/TR/gamepad/#remapping)

**実機のDS4での接続確認は未実施**です。標準配置のDS4相当入力をブラウザーで模擬し、操作・長押し・設定保存・切断復帰を自動検証しています。OS・ブラウザー・USB/Bluetooth・変換ソフトによる違いは、実機で確認する必要があります。

## ルールと実装範囲

SRS（I専用キック含む）、7-bag、HOLD、NEXT 5、ゴースト、DAS/ARR、接地猶予、T-Spin/Mini、B2B、更新後REN表、全消し、FIFO相殺、受信保留、おじゃま、top-out、ラウンド戦を実装しています。

原作と未照合のタイミング・境界条件は、[ゲームルール](docs/game-rules.md)の暫定値です。完全互換を保証するものではありません。実装の区切りと未実装項目は[実装状況](docs/implementation-status.md)を参照してください。

ネット対戦、サーバー、アカウント、CPUはまだ実装していません。ローカル対戦のエンジンはブラウザー依存を持たず、後続のサーバーから共有できる構成です。

## 開発とテスト

```bash
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

Linuxでブラウザー用の共有ライブラリが不足する場合は `npx playwright install --with-deps chromium` を使います。

| ディレクトリ    | 内容                                                   |
| --------------- | ------------------------------------------------------ |
| `packages/core` | 決定的な60Hzエンジン、回転・攻撃・乱数・対戦・リプレイ |
| `apps/web`      | Canvas描画、入力、ゲームパッド設定、画面、音           |
| `tests/unit`    | ルール・乱数・パッド変換・リプレイのテスト             |
| `tests/e2e`     | ブラウザー操作、DS4相当入力、切断、レイアウトのテスト  |
| `docs`          | [設計書・調査・検証計画](docs/README.md)               |

効果音はブラウザーで合成し、画像・音楽・キャラクター等の原作アセットは使用していません。ゲームパッドの入力はローカルで処理します。
